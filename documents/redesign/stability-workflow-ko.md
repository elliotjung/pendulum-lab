# S20 안정성·분기 도구

## 사용 경로와 분석 대상

`next.html#/lab/{systemId}`의 **분석 → 고정점 · 주기궤도 · 분기와 안정성**에서 연다. 도구를 열 때만 화면·계산 모듈을 불러오며, 계산은 작업마다 독립 worker에서 실행한다.

| 도구 | 분석 대상과 기존 계산 경계 |
|---|---|
| 반환 맵 고정점 | 현재 단일 구동 진자의 실제 구동 위상 단면. `findPeriodicOrbit`, `classifyFixedPoint` |
| 주기궤도 shooting | 같은 반환 맵의 지정 주기와 초기 추정. `findPeriodicOrbit`, `buildPeriodicOrbitDatabase` |
| Floquet | 수렴한 현재 구동진자 궤도의 물리 2×2 블록 또는 별도의 선형 감쇠 발진기. `floquetAnalysis`, `floquetLinearSpectrum` |
| Melnikov | 현재 구동진자 매개변수의 약섭동 분리선 근사. 해석식과 수치 적분 대조 |
| 자연 매개변수 continuation | 현재 위상 단면을 보존한 구동진자 branch. 지정 매개변수·범위·추정값과 잔차를 저장 |
| pseudo-arclength | 독립 기준 잔차 `x²−λ=0`. fold 통과와 끝점 방향 보존 |
| branch switching | 독립 pitchfork 기준 모델의 비영 branch 또는 현재 구동진자 주기배가 후보 |
| Neimark–Sacker | 독립 delayed-logistic 평면 맵의 복소 승수 교차 후보 |
| torus | 같은 평면 맵의 불변 원 collocation·불변성 잔차·유한 반복 Lyapunov 진단 |
| Arnold tongue | 독립 sine-circle 맵의 고정 결합 강도에서 회전수·유리수 잠금 스캔 |
| 두 매개변수 지도 | 현재 구동진자 두 매개변수 격자의 유한시간 Lyapunov 부호. 여차원 2 특이점 인증이 아님 |

기존 카탈로그 13개 정의의 ID·native export 참조를 보존한다. 11개 작업 도구가 관련 계산을 묶어 제공한다. 독립 기준 모델은 현재 진자나 양자 상태의 분기 결과로 표시하지 않는다. 다른 시스템에서도 기준 모델을 실행할 수 있으나 현재 모델용 반환 맵 계산은 호환되지 않는 이유와 함께 거부한다.

## 해·branch·실패 복구

- 초기 추정과 설정은 실행 전에 편집·검증한다. 구동진자의 sine 위상과 기존 cosine 엔진의 차이는 정확한 위상 이동으로 연결한다. 반환 시간은 주기의 정수 분할이며 물리 설정을 조용히 대체하지 않는다.
- 표와 그래프는 실제 해·매개변수·잔차·수렴 여부를 표시한다. 수렴 기록은 계산기가 반환한 해결 단계의 최종 잔차이며 제공되지 않는 Newton 내부 이력을 꾸며내지 않는다.
- 실패·부분 branch·비수렴은 완전한 branch와 구분한다. 잘못된 입력·worker 실패·취소·잘못된 파일이 현재 실험이나 마지막 성공 결과를 덮어쓰지 않는다.
- 저장된 유효 끝점에서 지원되는 branch를 다시 계산할 수 있다. fold 뒤에는 끝점 접선의 매개변수 방향을 보존한다. 정확한 특이 fold에서 시작할 수 없는 native 알고리즘 한계를 설명한다.
- 수렴한 현재 구동진자의 주기 1 해를 고정점·shooting·Floquet·진폭 continuation의 다음 추정값으로 전달할 수 있다. 원래 실험·입력 ID·부모 결과를 함께 유지한다. 변경된 continuation 매개변수를 다른 물리 모델에 조용히 이식하지 않는다.
- torus의 전체 곡선과 회전수는 저장·복원한다. native API가 저장 곡선으로 시작하는 기능을 제공하지 않아 torus 끝점 재시작은 제공하지 않는다.

## 저장 형식과 계보

`pendulum-stability-workflow/v1` JSON은 원래 canonical 실험 snapshot, 분석 대상, 설정·추정값, 결과·단위·경고, 알고리즘 버전, 입력 실험 ID, artifact ID와 UTC 생성 시간을 보존한다. 재시작은 부모 artifact와 동일 입력 실험 ID를 참조한다.

`inputRunId`는 이 단계에서 **입력 실험 snapshot의 식별자**다. 실행·관측 궤적을 실제 저장한 run repository의 ID라고 주장하지 않는다. 독립 진단의 원래 실험 의미와 재시작 관계를 보존하며, 프로젝트/run/artifact 저장 계층은 S24 범위다.

가져오기는 결과를 재표시한다. 현재 Lab의 조건·실행 데이터는 변경하지 않는다. 미래 버전, 알 수 없는 필드, getter·위험 키·희소 배열·순환, 비유한 수, 잘못된 단위·계산법·source·계보는 거부한다.

가져오기 검사는 schema와 저장된 요청에 대한 물성·단면·계산법의 일관성을 확인한다. 외부 파일의 수치 결과를 다시 계산하거나 진위를 인증하는 검사는 아니다.

## 자원·과학적 한계

- artifact 8 MiB, 결과 8192행, branch 256점, 상태 최대 8차원, 사전·실행 누적 계산 예산 2,000,000 work. work는 도구마다 보수적으로 평가한 작업 단위이며 경과 시간 예측이 아니다.
- worker 취소는 종료로 격리하고 오래된 응답을 버린다. 30초 응답 부재 시 종료한다. 제공되지 않는 내부 진행률은 표시하지 않는다.
- 연속 ODE 고유값과 반환 맵 승수를 혼용하지 않는다. 위상·시계 확장 좌표 전체의 RHS=0을 일반 평형점으로 해석하지 않는다.
- 양의 감쇠 단일 구동진자의 2D 반환 맵에 대해 NS crossing이나 torus를 꾸며내지 않는다. NS·torus 기준 결과는 별도 평면 맵이다.
- 약섭동 Melnikov, 유한 표본 분기 탐지, 유한 반복 회전수·Lyapunov 값, 유한차분/격자 추정은 엄밀한 존재·혼돈·특이점의 증명이 아니다. 해상도·기간·적분 간격·허용치 수렴을 확인해야 한다.
- 사람의 과학 검토는 수행하지 않았다. 기존 Learn의 검증 등급·보안 위험 수용 상태는 이 단계에서 변경하지 않는다.
