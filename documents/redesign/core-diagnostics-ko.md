# S18 핵심 카오스 진단

## 사용 경로와 해석

`next.html#/lab/{systemId}`의 분석 패널에서 `핵심 진단`을 열어 같은 도구를 사용한다. 기존 시스템별 분석과 실행·저장·공유 경로는 유지한다. 계산할 수 없는 도구에는 필요한 데이터나 모델 조건을 표시한다.

기록 기반 진단과 모델 기반 진단은 입력이 다르다.

| 진단 | 입력과 결과 | 주의할 조건 |
|---|---|---|
| 상태 / 시간 | 실제 보관된 좌표 또는 명시된 관측량 | 좌표 이름·단위와 가로축의 시간/iteration을 확인한다. |
| 에너지 | 해당 native 모델이 제공한 에너지 | 비보존계의 에너지 변화는 수치 오차와 같지 않다. |
| 위상 | 선택한 두 실제 좌표/관측량의 투영 | 투영은 전체 상태공간이 아니며 양자 확률을 고전 정준좌표로 해석하지 않는다. |
| FFT | 균일 표본의 스펙트럼 | Nyquist 한계, 관측 기간, 창·평균 제거 및 표본 절단을 확인한다. |
| NAFF | 균일 표본의 지배 주파수 | 유한 구간·잡음·복수 peak 영향이 남는다. 실수 신호의 양·음 주파수 쌍을 구별한다. |
| Poincaré | 연속 native 운동방정식의 사건 단면 | 기록을 직선으로 잇는 교차 근사가 아닌 기존 사건 검출기를 사용한다. 교차가 없을 수도 있다. |
| Lyapunov spectrum | native 변분 방정식과 재직교화 | 좌표 척도·유한시간·과도구간·수치 Jacobian에 의존한다. Hamiltonian 검사는 해당 모델에서만 의미가 있다. |
| SALI | 두 접선 벡터의 정렬 | 단일 유한시간 값이 카오스의 증명은 아니다. |
| FLI | 접선 벡터의 성장 | 적분 기간·정규화·초기 방향을 함께 비교한다. |
| 0–1 검사 | 유한 스칼라 시계열의 확산 통계 | 잡음, 과표본화, 짧거나 상수인 신호로 확정 분류하지 않는다. |
| 궤도 신뢰 시간 | 같은 native 모델의 후보·세분 참조 적분 비교 | 엄밀한 참 궤적 shadowing 정리를 검증하지 않는다. 관측 구간에서 임계값 미초과를 무한 신뢰 시간으로 표시하지 않는다. |

## 보존과 호환성

- 원래 초기조건에서 수행하는 별도 분석은 현재 애니메이션의 이어달리기가 아니다. 분석 설정과 실제 사용한 적분법을 결과와 함께 보존한다.
- hybrid 사건·접촉, 구속 투영, 지연 이력, 확률 잡음, 이산 맵·양자 진화에 연속 ODE 접선 모델을 임의로 적용하지 않는다. 이런 시스템도 실제 관측 시계열이 있으면 기록 기반 진단을 사용할 수 있다.
- 정적 스펙트럼·평형 진단의 평가 번호를 시간으로 바꾸지 않는다. 양자 관측량에는 이름과 단위를 붙이고 존재하지 않는 고전 좌표를 만들지 않는다.
- 보관된 표본은 원시 모든 step과 다르다. FFT/NAFF는 실제 시각의 균일성을 검사한다. 끝의 짧은 구간이나 누락·불규칙 sampling을 조용히 보간하지 않는다.
- 가로축은 `s`, `normalized-time`, `iteration`을 구분한다. Duffing·Van der Pol·Mathieu·자기·격자/장 계열의 정규화 시간을 SI 초로 표시하지 않는다. FFT는 cycles/해당 시간, NAFF는 rad/해당 시간이며 둘의 2π 차이를 유지한다. 구동 계열 에너지는 cart-pole의 J와 나머지 단위질량당 m²/s²를 구분한다.
- 분석은 별도 worker에서 실행한다. 취소 시 worker를 종료하고 늦게 도착한 결과를 폐기한다. 진행률이 미정인 작업에는 실제 수행한 일을 표시한다.
- 분석 결과 파일은 버전이 있는 독립 artifact다. 원 실험 설정, 좌표·단위, 분석 설정·버전, 결과와 경고를 보존한다. 재로드는 원 실험이나 기존 저장 데이터를 덮어쓰지 않는다.
- 파일 구조·크기·숫자·버전을 검사하며 실패 시 원본 보존 안내를 제공한다. JSON 결과의 유한하지 않은 값은 암묵적으로 변환하지 않는다.

현재 매끄러운 native RHS 연결은 22개 시스템이다. 13개 모델에는 위의 hybrid·구속 투영·지연·잡음·이산 전파·정적 평가에 맞는 설명을 제공한다. 이는 기존 계산 기능 삭제가 아니며 해당 시스템의 원래 분석과 기록 기반 도구를 보존한다. 제어 포화가 활성화되었거나 비매끄러운 구동 파형을 사용한 경우도 연속 접선 진단에서 거부한다. FPUT·chimera의 별도 ODE 분석은 관측 실행의 Verlet·midpoint RK2와 적분법이 다르므로 결과에 이를 기록한다.

분석 입력은 최대 8,192표본·256좌표·1,000,000개 상태값이며, 별도 ODE 계산은 총 100,000 step 이하다. 접선 계산은 최대 32차원과 `step × 차원² ≤ 2,000,000` 예산을 적용한다. artifact 파일은 최대 16 MiB이며 기존 실험 저장·공유의 크기 제한은 변경하지 않는다. 결과 기록 간격과 참조 세분화에도 별도 예산을 적용한다. 상한을 넘기면 기간·차원·기록 간격을 조절하는 안내를 표시한다.

## 검증과 한계

수치 fixture와 native 호출 동등성, 전체 호환성 matrix, worker 취소/오류, artifact 왕복 및 desktop/mobile 사용자 여정의 최종 결과는 `stage-runs/S18-verification.json`에 기록한다. 이 문서의 구현 설명만으로 검증 완료를 뜻하지 않는다.

기존 `app.html`, 계산 엔진·공개 API·저장 형식은 복구 경로로 남는다. S19 이후 고급 분석이나 새 교육 콘텐츠는 이 단계의 범위가 아니다. 자동 검증과 agent의 화면 검사는 사람의 과학 검토가 아니다. S01의 공급망·CodeQL 미해결 위험도 별도로 유지한다.
