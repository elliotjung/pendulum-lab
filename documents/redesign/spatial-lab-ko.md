# S12 공간 진자 실험실

## 경로와 계산 경계

병렬 진입점 `next.html`의 다음 네 경로에서 공간 진자를 제공한다.

| 경로 | 기존 공용 엔진 | 상태 표현 |
|---|---|---|
| `#/lab/spherical` | `SphericalPendulum` | 극각·방위각과 그 시간 미분, 4개 성분 |
| `#/lab/spherical-chain` | `SphericalChain` | 링크별 극각·방위각을 먼저, 그 뒤 속도를 배치한 4N 성분 |
| `#/lab/spherical-embedded` | `EmbeddedSphericalPendulum` | 단위 방향 u와 방향의 시간 미분 w=du/dt, 6개 성분 |
| `#/lab/spherical-embedded-chain` | `EmbeddedSphericalChain` | 모든 링크의 u 다음 모든 링크의 w를 배치한 6N 성분 |

새 product adapter는 기존 클래스의 적분과 투영을 호출한다. 별도 운동방정식을 만들지 않는다. 단일 모델의 단위 질량당 에너지는 질량을 곱해 J로 표시한다. 사슬은 새 Lab에서 1–16개 링크를 지원하며, 기존 엔진과 공개 API의 지원 범위는 변경하지 않는다. 극좌표 사슬은 RK4/RK2/Euler를 제공하고 나머지는 기존 전용 RK4를 사용한다.

## 좌표·단위·과학적 한계

- 오른손 xyz 좌표계, 위쪽 +y, 중력 −y, 고정점 원점이다. θ는 아래 수직선에서 측정하고 φ는 +x에서 +z로 증가한다.
- 위치는 m, 속도는 m/s, 각도는 rad, 각도 미분은 rad/s, 질량은 kg, 에너지는 J이다. 위치에너지의 기준 높이는 고정점이다.
- embedded u는 무차원 단위 방향이고 w=du/dt는 1/s이다. w를 각속도 벡터와 혼동하지 않는다. 초기조건은 |u|=1, u·w=0을 만족해야 한다.
- 각운동량은 실제 `Σ r×mv`를 kg·m²/s로 표시한다. 수직 성분은 `Ly=Σm(z vx−x vz)`이다. 기존 단일 진자의 `Lz` 함수는 반대 부호를 사용하고 사슬의 `Lz` 함수는 이 +y 부호를 사용한다. 제품은 같은 좌표계로 통일한다.
- 중력 아래에서는 전체 각운동량 벡터가 보존되지 않는다. 무감쇠에서 에너지와 수직 성분의 보존 및 중력축 주위 회전 대칭을 검사한다. 감쇠가 있으면 물리적 소산과 적분 오차를 구별한다.
- 각좌표는 극점에서 특이하며 기존 정규화가 궤적을 교란할 수 있다. 극점 통과에는 embedded 계를 사용한다. embedded 계의 매 단계 정규화·접선 투영은 원래 알고리즘의 일부이며 에너지 보존을 보증하는 것은 아니다.
- 표시하는 길이 잔차(m), 단위벡터 잔차(무차원), 접선 잔차(1/s)는 단위가 다르다. 투영 후 잔차가 작더라도 시간 적분 오차가 작다는 증거는 아니다. 시간 간격을 줄인 비교가 필요하다.
- 질량 없는 고정 막대 모델이며 줄 이완, 충돌, 자기 접촉을 구현하지 않는다.

## 사용 흐름

조건 패널에서 링크와 물성·초기조건을 편집한 후 `조건 적용`으로 한꺼번에 검증한다. 여러 embedded 성분을 편집하는 동안에는 실행과 저장이 비활성화된다. `편집 취소`, 기본 예제, 보관한 설정 또는 유효한 상태 JSON으로 복구할 수 있다.

작업 공간은 3차원 직교 투영을 사용한다. 방향키와 회전 버튼으로 카메라를 이동하고 +/−로 확대·축소하며 Home 또는 시점 초기화로 되돌린다. 포인터·터치 드래그를 지원한다. xz 평면, 속도 벡터, 각운동량 방향을 켜고 끌 수 있다. 벡터 길이는 표시 범위에 맞춰 제한되므로 크기의 정량 비교에는 수치 표를 사용한다. 카메라는 실험 초기조건을 변경하지 않는다.

WebGL을 사용할 수 없거나 표시가 중단되면 SVG 투영으로 전환한다. 계산 worker, 숫자 표, 분석 그래프와 CSV는 계속 접근할 수 있다. 카메라 조작은 물리 계산과 독립적이다.

## 저장·내보내기와 자원 한계

새 저장 키 `pendulum-product/spatial/v1/`만 사용한다. 손상되거나 미래 버전인 기존 항목은 자동 덮어쓰지 않는다. canonical JSON과 공유는 SI 단위, native 3차원 초기조건, 적분기·표본 설정 및 출처를 보존한다. 파일 가져오기는 200,000바이트로 제한하며 다른 시스템·알 수 없는 버전·지원하지 않는 필드를 거부한다. S12의 에너지·각운동량·구속 잔차 표시는 고정 진단이다. 범용 분석 실행은 연결하지 않았으므로 비어 있지 않은 `analyses` 요청은 명시적으로 거부하고 원본을 보존한다.

저장·공유는 초기조건에서 다시 실행하는 설정이다. 카메라나 실행 중 적분기 내부 상태를 재개하는 형식으로 주장하지 않는다. CSV는 기록된 3차원 위치·속도·각운동량·구속 잔차·에너지를, SVG는 선택한 분석과 설정 정보를 담는다. 표본 축약과 실제 기록 간격을 화면에 안내한다.

한 실행은 최대 100,000단계, 결과는 최대 2,001표본이며 worker 요청은 최대 64단계 및 약 8ms 협력 예산을 사용한다. 하나의 기존 엔진 단계는 나눌 수 없다. 응답 제한은 15초이다. 취소·오류 시 worker를 종료하고 현재 화면에 마지막 검증된 수신 결과를 보존한다. 라우트 이동 시에도 계산은 종료되며, 초기조건과 보관 설정만 같은 페이지 세션에 유지한다. 돌아왔을 때 이전 궤적이나 실행 중 표본을 복원하지 않는다.

## 보존·검토·복구

S12는 `app.html`, 기존 physics/chaos/research/runtime/workers/validation, 공개 API, 사용자 자료, S03 계약과 lockfile을 변경하지 않는다. S13 이후 시스템이나 교육 콘텐츠는 추가하지 않는다. 기존 npm·CodeQL 보안 항목과 과학 콘텐츠 사람 검토 상태는 이번 작업의 해결 범위가 아니다.

구현 검증 수치와 실제 원격 commit 증거는 `stage-runs/S12-progress.md`와 최종 검증 기록에 남긴다. 자동 수치·코드·화면 검사는 물리 전문가 검토를 뜻하지 않는다. 기존 앱은 계속 사용할 수 있으며 이전 완성 단계의 참조는 S11 `200193d`이다.
