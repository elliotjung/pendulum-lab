# 관측 데이터·역문제·불확실성 워크플로 (S22)

`next.html#/lab/{systemId}`의 분석 도구에서 **관측 데이터 · 매개변수 추정 · 불확실성**을 연다. 모든 사용자가 접근하며 학습 진도에 따른 잠금은 없다.

## 관측 가져오기

1. CSV/센서 CSV를 선택하거나 붙여넣는다. 각도 채널 또는 마커 좌표와 시간 열을 지정한다. 녹화 영상은 두 색상 표식을 사용하며 원본·추출 화면 크기와 고정점을 확인한다.
2. 원본 단위와 보정 배율·영점·시간축 이동을 지정한다. 시간은 엄격히 증가해야 하며 자동 정렬·중복 제거를 하지 않는다. 결측값은 거부, 해당 행 제외, 최대 간격을 제한한 시간 선형 보간 중 선택한다. 끝점 외삽과 시간 결측 보간은 하지 않는다. 각도 wrap을 자동으로 풀지 않는다.
3. **관측 미리보기**에서 변환 후 s/rad 표본과 원본/변환 ID·이력을 읽는다. 설정을 바꾸면 미리보기를 다시 만들어야 한다.
4. **미리보기 확인 · 관측 가져오기 확정**을 눌러야 계산 입력으로 채택한다. 새 가져오기 실패 시 이전에 확정한 관측과 결과는 보존한다.

원본 CSV 텍스트와 영상 바이트, SHA256, 추적/보정 설정, 변환 이력과 변환된 표본을 `pendulum-observation/v1` 파일에 함께 저장한다. 원본과 변환 자료는 deep freeze하며 복원 시 원본 해시와 변환을 재생해 대조한다. 센서 입력은 시간과 각도/좌표가 들어 있는 수치 CSV이며 임의 제조사 바이너리 프로토콜을 자동 해독하지 않는다. 단일 각도 센서 자료도 보존하지만 이중진자 추정에는 두 각도가 필요하다.

영상은 기존 `trackDoublePendulumFrame`을 호출하는 로컬 색상 마커 추적이다. 물체 자동 인식이나 길이·질량 추론이 아니다. 고정점은 최대640×480으로 축소한 추출 화면 좌표이며 원본 화면 좌표와 배율을 구별한다. 물리적 길이·초기 각속도는 Lab에서 별도로 정한다. 영상 코덱 지원은 브라우저에 따른다. 표식 가림은 결측 정책으로 처리하고 실패·취소 시 영상 listener와 object URL을 해제한다.

## 매개변수 추정

기존 `fitDoublePendulum`과 `rhsDouble`/RK4를 그대로 호출한다. 지원 대상은 점질량 이중진자, RK4, 시작 시간0이며 관측도 t=0에 정렬되어야 한다. 알려진 초기 각도·각속도와 고정 gamma를 사용한다. 다른 모델·적분기를 기본값으로 대체하지 않는다. UI와 계약은 g/l1/l2/m1/m2 중 최대 세 물성을 지원한다. 무감쇠에서 두 질량의 공통 배율을 동시에 추정하는 비식별 조합은 거부한다.

추정값·범위·SI 단위, RMSE/cost, 수렴 상태, 표준오차·공분산과 한계를 보여 준다. 반복 상한이나 damping 한계에 도달한 결과는 수렴 성공으로 표시하지 않는다. 기존 fitter는 관측 시각에 정확히 도달하도록 각 구간을 세분화하므로 고정 Lab 격자와 관측 격자가 다르면 마지막 부분 step이 달라질 수 있다. 초기 각도 추가 추정 등 기존 공개 API의 나머지 옵션은 보존하며 이 UI가 전부 노출한다고 주장하지 않는다.

표준오차는 국소 선형화와 잔차 가정에 의존한다. 전역 식별 가능성이나 posterior 신뢰구간을 보장하지 않는다. 계산할 수 없는 공분산/오차 값은 null로 보존한다. 추정 결과의 평가 수는 기존 kernel이 보고하는 최적화 반복 수이며 내부 전방 적분 호출 횟수는 별도 계측되지 않는다.

## Sobol·PCE·surrogate

공용 canonical physics adapter를 실행하여 선택한 상태 성분의 마지막 값/기록 표본 산술평균/RMS를 계산한다. 기존 batch builder가 허용하는 독립 scalar/vector 성분만 범위 변수로 선택한다. 숨겨진 구조·runtime 별칭을 임의로 변경하지 않는다. 실제 지원하지 않는 범위·상태는 설명과 함께 거부한다.

- Sobol은 기존 `sobolIndices`의 고정 결정론적 표본열과 Saltelli/Jansen 추정기를 사용한다. N(d+2)회 평가하며 원래 음수·1 초과 추정치를 보존한다. 분산0이면 지수가 정의되지 않음을 보고한다. seed로 이 표본열을 무작위화하지 않는다.
- PCE는 기존 `latinHypercube`로 훈련과 별도 seed의 검증 설계를 만든다. 기존 `fitPolynomialChaos`의 정규화 Legendre 기저를 사용하고 R²·조건수·별도 검증 RMSE/최대 오차를 표시한다. 훈련 표본은 기저 항 수의 두 배 이상을 요구한다. 계수와 표본을 보존하고 동일 native fitter로 surrogate를 복원하며 범위 밖 예측은 거부한다.
- 독립 균등분포 가정이다. 상관 입력, posterior 추정, 전체 장기 거동의 보증과 신뢰구간을 포함하지 않는다. 확률계는 원래 seed를 고정하는 공통 난수 조건부 민감도이며 seed 변동성은 따로 탐구해야 한다.

## 파일·계산 경계

원본 CSV는2MiB/4096행/16열, 전체 관측 파일16MiB, 영상8MiB/60초/원본8Mi pixels·각 변8192px/최대256프레임/24Mi pixel 추출 작업량, 역문제 결과 파일24MiB로 제한한다. 추정 입력은3–1024표본, 최대80반복·전방4096step, UQ는1–3변수·8–256기본표본·PCE1–3차다. 추정/UQ 모두 추정 작업량400만 상한을 검사한다. native LM의 거절 step과 Jacobian/covariance 비용도 추정 예산에 포함한다.

계산은 별도 worker에서 실행하며 진행·오류·취소를 보고한다. native 동기 추정 반복 내부의 세밀한 진행률은 제공되지 않아 해당 구간은 미정 진행으로 표시한다. worker 무응답30초, 영상 event 무응답10초·전체120초 제한을 둔다. 취소는 worker를 종료하며 이전 완료 결과를 보존한다. interrupted optimizer의 내부 상태 재개는 제공하지 않는다.

`pendulum-inverse-result/v1`은 입력 canonical snapshot, 알고리즘 버전, 설정, 결과·단위와 원본 관측을 포함한다. 관측→변환→추정 결과의 관계를 파일로 복원한다. 이 단계는 S24의 영구 프로젝트 저장·ZIP 패키지를 구현하지 않는다. 현재 Lab 조건과 불러온 파일의 입력 snapshot을 구별하며 파일 가져오기로 현재 조건을 덮어쓰지 않는다.

formula·비수치 셀, 위험한/중복 열 이름, 잘못된 quote·차원·단위·schema·객체 속성·경로 파일명·크기 초과를 거부한다. 해시와 재생 검사는 자료 내부 일관성을 검사하며 외부 수치 결과나 촬영 내용의 진실성을 인증하지 않는다. 전방 물리 모델 전체를 파일 복원 때 다시 계산한 것으로 표시하지 않는다.

## 검증과 보존

`tests/product/observations/`, `tests/product/analysis/inverse/`, production `e2e/redesign/observations-inverse.spec.ts`가 입력 공격·보정·원본 왕복·native parameter recovery·UQ benchmark·worker 경계를 검증한다. `scripts/redesign/measure-inverse-workflow.ts`는 native 관측을 ms/deg로 변환해 g를 복원하고 표준 사상의 선형 극한에서 해석적 Sobol/PCE 분산비와 비교한다. 최종 건수와 실행 증거는 `stage-runs/S22-verification.json`에 기록한다.

기존 엔진·공개 API·저장/공유 형식·`app.html`·golden과 이전 테스트는 보존한다. 전체 parity와 사람의 과학 검토를 인증하지 않는다. 실물 센서·실제 촬영 조건·물리 장치와 screen-reader 음성은 별도 현장 검증이 필요하다. S22는 사용자 review gate가 아니며 다음 유효 단계는 S23이다.
