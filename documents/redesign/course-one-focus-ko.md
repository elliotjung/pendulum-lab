## 구현 경계

`content/learn/course-1/`의 단원 모듈은 순수 데이터다. 실행 종류, 노출·고정 변수, preset, plot, 관찰 과제와 실험실 전달을 선언하며 계산 함수를 담지 않는다. `schema.ts`와 콘텐츠 검증은 지도와 ID·제목의 일치, 완전한 변수 정의, 인용, 실행 가능 시스템·적분기, 고정 조건 및 실행 예산을 확인한다.

`src/product/experiments/runtime.ts`는 S07의 `createPlanarSimulation`을 사용한다. 질량행렬·에너지 분해·순간 가속도 진단은 `src/product/adapters/physics/focus-diagnostics.ts`가 기존 에너지와 도함수의 평가 결과를 읽는다. 정상모드 기준선은 기존 모델의 평형 Jacobian으로부터 만든다. 새 교육용 운동방정식이나 별도 물리 엔진을 도입하지 않았다.

Focus 실행은 최대 **20초·20,000 적분 단계**, 저장·표시 결과는 최대 **801개 표본**으로 제한한다. 현재 preset은 RK4, 간격 0.002 s이며 1.1–1.7은 8 s, 1.8은 20 s다. 실행은 작은 작업 묶음 사이에서 이벤트 루프에 제어를 반환하여 진행·취소를 처리한다. 긴 자유 탐구는 실험실에서 기간과 분석을 확장한다. 최대 오차·에너지 변화 readout은 표시 표본에서 계산한 값이며, 모든 적분 단계나 연속시간 전체의 엄밀한 상한을 뜻하지 않는다.

Focus는 공개 단원에서만 지연 로드된다. 불러오기 취소·실패·재시도, 잘못된 입력, 계산 취소·오류, 저장 불가 상태를 표시한다. 유효한 여러 입력은 함께 적용되고 실패한 편집은 기존 설정과 결과를 보존한다. 고정 변수는 복원된 데이터에서도 검사한다. 실행 중에는 편집과 실험실 전달을 비활성화하며, 재실행은 현재 설정의 초기조건에서 시작한다.

그래프는 제목·범례·실제 표시 축 범위를 본문 크기의 텍스트로 함께 제공한다. 작은 수는 지수 표기로 표시하고, 곡선은 실선·파선·점선으로도 구별한다. 좁은 화면에서는 축소된 그림 안의 문자를 숨기고 그림 위의 설명을 읽도록 구성했다. 그래프의 수치 readout은 실행 중 자동 음성 알림을 반복하지 않는다.

기존 `physics/`, `chaos/`, `research/`, `runtime/`, `workers/`, `validation/`와 공개 API·기존 저장 형식은 보존 경계다. 이 단계의 변경은 제품 계층의 adapter·Focus·Learn·Lab 연결과 관련 콘텐츠·검증에 한정한다. 이후 시스템 패밀리, 일반 sweep/ensemble 도구, 새 과정 제작, migration, 기본 앱 전환은 S09 범위에 포함하지 않는다.

## 실험실 전달과 복귀의 의미

`실험실에서 계속`은 **현재 Focus 설정의 초기조건**을 보낸다. 시스템, 물성, SI 단위, 초기각·각속도, 적분기·기간·시간 간격, 분석 설정을 기존 canonical experiment/share/route 계약으로 직렬화한다. 출처에는 `learn:course-1:1.N:v1` 형태의 단원과 콘텐츠 버전을 기록한다. 계약에서 허용하는 seed·부모 experiment 참조·원래 입력 단위 이력도 유지한다. 현재 애니메이션의 마지막 좌표에서 이어 적분하는 기능으로 해석하지 않는다.

Lab은 전달된 설정을 읽어 실제 실험을 준비하고 출처 단원 링크를 표시한다. 같은 탭에서 브라우저 뒤로가기 또는 출처 단원으로 돌아오면 해당 Focus의 설정과 제한된 결과, 선택한 해석 항을 유지한다. 실행 중 페이지를 떠나면 Focus 계산을 취소한다. Lab에서 자유롭게 바꾼 값은 Focus의 고정 조건에 자동으로 역으로 덮어쓰지 않는다.

새로고침은 해당 단원의 **재실행 설정**을 복원하며 완료된 궤적은 다시 계산한다. 설정은 `sessionStorage`의 `pendulum-product/focus/v1/{courseId}/{unitId}`에 저장하고, 학습 진도용 `localStorage` 및 기존 사용자 데이터와 분리한다. 탭 세션이 끝난 뒤의 영구 저장이나 탭 간 동기화를 약속하지 않는다.

손상·미래 버전·다른 출처·과도한 크기·고정 조건에 어긋나는 저장 데이터는 덮어쓰지 않는다. 화면은 기본 설정과 저장되지 않는 연습 상태를 안내한다. 저장소 접근 실패나 quota 오류가 있어도 화면 안의 연습은 가능하며, 복원 가능 여부를 명시한다.

## 과학 검증 등급과 해석 주의점

- **automated-verified: 8/8** — 선언한 관찰값과 수치 fixture를 실제 실행했다. 콘텐츠 SI 차원·schema, 기존 golden, 속도·행렬·라그랑주 잔차, 정상모드, 에너지 교환, 가까운 궤적 및 런타임 오류·취소 검사가 근거다.
- **source-checked: 8/8** — 1차 자료의 관련 절과 식을 직접 대조했다. 출처·접근일·변환 판단은 [과학 콘텐츠 출처 기록](stage-runs/S09-source-review.md)에 있다.
- **human-reviewed: 0/8** — 사람 또는 물리 전문가 검토는 아직 완료되지 않았으며 제품에도 표시한다. 사용자 UI 구조 승인은 과학 전문가 검토를 대신하지 않는다.

기준 자료는 [Tong의 라그랑주 역학 강의](https://www.damtp.cam.ac.uk/user/tong/dynamics/two.pdf), [Tedrake의 다물체 동역학](https://underactuated.mit.edu/multibody.html), [Shinbrot 등의 이중진자 논문 원문](https://materias.df.uba.ar/mcaa2017c2/files/2017/08/AJPDoublePendulum2.pdf)이다. Tong의 아래쪽 양의 y와 MIT의 둘째 상대각을 이 앱의 위쪽 양의 y·두 절대각으로 변환했다.

Focus 색별 에너지는 아래 평형 영점이며 S07 Lab 총에너지의 지지점 높이 영점과 상수만큼 다르다. 1.7은 `Eshift = E - Emin`을 명시한다. 1.4의 항 선택은 같은 순간의 기여를 보여 주며 실제 운동은 전체 방정식으로 계산한다. 1.8의 양의 유한시간 성장률만으로 장기 카오스를 확정하지 않으며, 첫 각도만 바꾸어 생긴 작은 에너지 차이와 수치 오차의 영향도 설명한다.

## 아직 확인할 범위

자동 DOM/접근성 검사나 Chromium의 mobile emulation은 실제 스크린리더 음성 흐름, 실제 휴대기기, 다른 브라우저·운영체제의 검증을 대신하지 않는다. 실제 음성 읽기와 그 밖의 브라우저·기기 범위는 확인되지 않았다. 브라우저 여정과 시각 검증 결과는 검증 보고에서 구체적인 환경·통과·실패와 함께 확인할 수 있다.

기존 보안 기준선의 미해결 항목에 대한 해결·위험 수용을 이 문서에서 새로 주장하지 않는다. 의존성 교체나 공급망 이슈 해결은 이번 콘텐츠/Focus 범위 밖이다. 원격 checkpoint와 최종 상태 commit의 존재, 보존 검사, 남은 회귀 위험은 [단계 진행 기록](stage-runs/S09-progress.md)을 확인한다.
